# Agent Rules

## Keep the README in sync

- Update the root `README.md` whenever exam directories are added, renamed, moved, or removed.
- Ensure the exam list, file paths, links, and run instructions match the actual repository structure.
- Update each affected exam's README when its setup, files, or requirements change.

## Verify accuracy

- Read the relevant exam instructions and files before making changes. Do not guess requirements or invent details.
- Check that referenced files exist, links point to the correct locations, and documented commands work.
- Review the final diff for mistakes, inconsistencies, and unintended changes.
- Run relevant checks when available. Clearly report anything that could not be verified.
- Preserve unrelated work and do not modify exam data unless explicitly requested.

## Keep changes clean and readable

- Use clear headings, short paragraphs, and concise lists.
- Keep terminology, formatting, and file names consistent.
- Prefer simple, focused changes over unnecessary complexity or duplication.
- Make instructions easy for interns and junior developers to follow.
